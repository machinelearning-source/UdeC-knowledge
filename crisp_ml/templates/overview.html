Learning to rank KnowBot's sources

KnowBot is a Retrieval-Augmented Generation (RAG) chatbot that answers questions about the official documents of the University of Cundinamarca. Its answers are only as good as the fragments it retrieves. This project trains a Machine Learning model that re-ranks the retrieved fragments so that the page that answers the question comes first.
